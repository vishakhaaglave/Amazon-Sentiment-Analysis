# Customer Review Sentiment Analysis

## About the Project

This project is about analyzing customer reviews using Python and Natural Language Processing (NLP).

I used customer review data to understand what customers are saying and to identify whether their reviews are **Positive, Negative, or Neutral**.

I also explored the dataset, checked for missing values and duplicates, and created some visualizations to better understand the data.

## What I Did

- Loaded and explored the customer review dataset
- Checked the dataset for missing and duplicate values
- Performed basic data analysis and visualization
- Cleaned and processed the review text
- Used TextBlob to calculate polarity and subjectivity
- Used VADER to perform sentiment analysis
- Classified reviews into Positive, Negative, and Neutral sentiments

## Sentiment Analysis

I used two approaches for sentiment analysis:

**TextBlob**  
Used to find:
- Polarity
- Subjectivity

**VADER**  
Used to calculate positive, negative and neutral sentiment scores and classify the reviews.
